# 免费数据来源

以下来源使用公开网页或 HTTP 接口，无需 API key、登录或付费订阅。2026-10-01 已在线核验代表标的；接口没有可用性承诺，每次响应仍需校验标的、时间、价格和基准。备用覆盖不到的字段保留缺失。

东方财富日线备用已实现解析和故障切换测试，但本次环境在线请求返回 HTTP 503，不能宣称当前稳定可用。行业资金接口也可能返回 502。行业接口缺少可核验的交易日期，文案说明这一限制。

主要入口：新浪 `https://hq.sinajs.cn/list=...`、腾讯 `https://qt.gtimg.cn/q=...`、搜狐 `https://q.stock.sohu.com/hisHq?code=zs_000001&...`、东方财富日线 `https://push2his.eastmoney.com/api/qt/stock/kline/get?...`。

## 美股

| 内容 | 在线优先顺序 | 覆盖限制 |
| --- | --- | --- |
| 股票、11 类行业 ETF 常规报价与日线 | Yahoo → Nasdaq → Futu | Nasdaq 提供同源前收和成交股数；Futu 不补无证据的历史成交量 |
| 股票、ETF 真正盘前 / 盘后 | Yahoo → Nasdaq → Futu | 没有该时段实际交易时保留为空 |
| 道指、纳指 | Yahoo → Futu | 使用实际指数，不拿 ETF 或纳指 100 替代 |
| 标普 500、罗素 2000 | Yahoo → Cboe → Futu | Cboe 同源历史可校验前收 |
| VIX、10 年美债收益率 | Yahoo → Cboe → Futu | Cboe/Futu 的 TNX 原值除以 10 转成收益率百分数 |
| 4 个股指期货、美元、黄金、原油 | Yahoo → Futu | Futu 期货延迟约 10 分钟，基准为供应商结算价 |
| 股票、ETF 夜盘 | Yahoo BOATS → Webull 夜盘快照 | Webull 覆盖随榜单变化，没有逐股成交时间 |
| SPY 两日成交股数 | Yahoo → Nasdaq | 同源、同口径的两个完成交易日 |
| 中文快讯 | 华尔街见闻、东方财富 | 最新时间优先，不把摘要标题当具体事件 |

Yahoo 的 `query1` 与 `query2` 是同供应商的两个入口，不算独立来源。Futu、Nasdaq、Cboe 和 Webull 是独立备用供应商。普通盘后 19:59 的价格不属于 20:00 后夜盘。

SPY 股数使用各供应商披露的日线口径，可能包含延长交易，不宣称仅覆盖常规场；只比较同一来源的两个完成交易日。富途分钟量之和与页面总量不一致，未被用于全日股数或量能比较。

### Yahoo Finance

日线及延长交易使用 `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`，失败时尝试 `query2.finance.yahoo.com`。普通图表没有 BOATS 夜盘，真实夜盘从 `https://finance.yahoo.com/quote/{symbol}/` 的结构化报价提取，要求价格与对应真实成交时间同时存在。

### Nasdaq

`https://api.nasdaq.com/api/quote/{symbol}/historical?assetclass=stocks|etf&...` 返回实际日期、收盘价和成交股数。已经完成的交易日才按交易所闭市时间赋予日线收盘语义；这不是逐笔成交时间。

`.../extended-trading?assetclass=stocks|etf&markettype=pre|post` 采用交易行的实际价格和时钟，日期来自 `Data last updated`，不用 `resume updating` 的下一日。盘后涨跌从同源当日常规收盘重算，不使用仍比较前一日的汇总百分比。

### Cboe

报价 `https://cdn.cboe.com/api/global/delayed_quotes/quotes/{symbol}.json`，同源日线 `.../charts/historical/{symbol}.json`。映射仅 `_SPX`、`_RUT`、`_VIX`、`_TNX`。

时点采用 `data.last_trade_time`，不采用顶层文档更新时间。无时区时钟按美东解释，有偏移量则尊重源偏移。前收采用同源历史，避免 `prev_day_close` 收盘后滚动导致比较错误。

### Futu

公开页面 `https://www.futunn.com/stock/{symbol}-US` 的 `window.__INITIAL_STATE__` 提供报价时点与分钟线；期货用对应 `/futures/` 页面。页面较大，只在缺失时补取。

盘前、盘后按真实分钟线及 NYSE 时段判断。分钟线是结束时间，09:30 一条仍属于盘前。晚于盘后结束的状态字段不推断为夜盘。Futu 与 Moomoo 是同供应商，不重复计数。

### Webull 夜盘

采用 `https://quotes-gw.webullfintech.com/api/wlas/ranking/overnight?...` 的公开夜盘榜单，校验 `rankType=overnight`、`values.dt=overnight` 及美国标的。价格与普通盘后不同，确实是夜盘快照。

接口没有逐股成交时间，榜单 `latestUpdateTime` 也不是单只股票的行情时点。数据保留 `asof=None` 和独立 `observed_at`，图片、文案标注“夜盘快照 / 采集时间 / 成交时间未披露”。只在合法夜盘窗口内采用，04:00 后不把无成交时钟的快照当作最新盘前报价。

Webull 普通公开报价当前不提供真实夜盘字段。Stooq 在本次环境返回浏览器验证页；两者没有被当作严格实时夜盘备用。

## 回退与缓存

重要日程使用美国劳工统计局的公开 [ICS 发布日历](https://www.bls.gov/schedule/news_release/bls.ics)。按源的 `US-Eastern` / `America/New_York` 或 UTC 时区解析，尊重夏令时；仅选择未来 72 小时的非农就业、CPI、PPI、JOLTS 和就业成本发布。无明确时间、取消、已过期的事件不展示。请求限时 4 秒，源不可用时重点区显示观察条件，不推测日程或发布结果。

美股先尝试独立在线供应商，再读取本地缓存。缓存保留来源、原报价时间和原快照采集时间，标注“缓存”；读取不会刷新行情时间。交易日或时段不符的数据仍被拒绝。A 股目前只使用在线来源，不读取行情缓存。

字段不足时保留可用内容与说明，不用价格推测成交量，不用零值冒充缺失，不用旧收盘冒充最新夜盘，不混用单位。

## 历史与周报

每日规范化行情、新闻、来源、行情时点和原版面保存在持久归档中，独立于有时效的行情缓存。周报默认使用归档，不根据当前报价反推历史。

首期可选历史日线补录：A股使用搜狐 `hisHq` 或东财历史 K 线；搜狐第8列成交额单位为万元，东财成交额为元。美股使用 Yahoo 日线；备用为 Nasdaq 的股票/ETF历史、`COMP` 纳斯达克综合指数历史，以及 Cboe 指数历史。只接纳已闭市且标的匹配的交易日；日线赋予正式闭市语义，不声称逐笔成交时间。

历史补录记录原始来源、实际采集时间和 `origin=backfill`，不补录事前预期或过去的新闻。

发布结果优先使用无需密钥的 BLS `https://api.bls.gov/publicAPI/v2/timeseries/data/{seriesID}`。非农采用 `CES0000000001` 季调总就业人数（千人）月差转为万人，失业率采用 `LNS14000000`；CPI采用 `CUUR0000SA0` 同比、`CUSR0000SA0` 环比，核心对应 `SA0L1E`；PPI采用 `WPUFD4` 同比、`WPSFD4` 环比。只读取目标统计月份及同源计算基准，保留 series ID、来源地址、计算方法和实际采集时钟；API 未披露实际发布时间，数据明确标为采集版本，可能包含修订。

见闻、东财快讯作为新闻证据与备用明确数值，保留原标题和来源，不冒充 BLS 官方正文。不同来源冲突而没有官方或人工核验结果时，仍标为待核实。归档、幂等、周度口径与备份见[历史与复盘](history.md)。
