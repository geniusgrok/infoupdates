# 历史与复盘

## 持久化与幂等

所有命令默认共用 `archive/`。`--output` 只改变便于发布的图片、文字位置；`--archive` 改变持久历史位置。任务应在固定工作目录运行，或为各命令指定同一个绝对归档路径。

```text
archive/
  market.sqlite3                    行情快照、版面索引、日程与数值证据
  index.html                        可筛选的静态历史页
  reports/日期/市场-时段/版本哈希/
    image.png                       当时的图片
    summary.txt                     对应的精简文字
    data.json                       完整采集数据、版面、时点和关联编号
```

采集快照按市场与规范化 JSON 的 SHA-256 唯一保存；JSON 键排序、保留数据时点，拒绝 NaN/Infinity，带时区时间统一记录为 UTC。相同快照重试只更新首次/最近采集时间范围。不同的数据、原行情时间、来源、缓存状态或采集快照时点均保留为不同快照。

版面以市场、时段、版面日期定位，以采集快照、实际版面内容、程序和字体摘要生成版本编号。只有运行生成时间变化不创建新版本，同一程序与输入重试使用原图片、文字与首次生成时点。输入、编辑结果、程序或字体变化会新增版本；图片和文字的公开同名文件采用该版面最新生成版本，较早任务迟到不会降级。

原数据在组装、绘图前单独提交，因此后续发布失败仍能留下采集快照。图片、文字、JSON 先生成到临时目录，文件同步后原子替换，再提交索引。并发写入采用 SQLite `BEGIN IMMEDIATE`；同一输入只会生成一次。失败明确报错，完整旧版本不删除；重试可修复未完成发布。同名公开 PNG/TXT 分别原子替换，跨文件一致性以不可变归档目录为准。

归档不会自动清理，短期 `.cache/briefs/` 可以独立删除。`archive/` 已加入 `.gitignore`，市场数据不提交到 main。

## 每周精选

```bash
python -m weekly --archive archive --output output
python -m weekly --week 2026-09-21 --archive archive
python -m weekly --backfill --archive archive
```

默认选择美东周五 20:00 已结束的最近交易周；显式 `--week` 必须为周一，未结束的周会拒绝生成。文件按该周周六日期命名，图中同时标明交易周、生成时间与日期星期。建议北京时间周六上午运行。

- 周涨跌从上周最后交易日到本周最后交易日的同源、同单位实际收盘计算。A股节假日与 NYSE 半日市分别处理；缺少端点不使用较早日代替，不累加日涨跌幅。
- 中间某日缺失不妨碍已知端点的周涨跌，但留存天数会明示。日均成交活跃度只在每个应交易日均有同源记录时计算；两周交易日数量不同时比较各自日均值。
- A股量能使用沪市人民币成交额，美股量能使用 SPY 供应商日线成交股数代理。两者不能直接比较数值大小，SPY 也不是全市场成交额。
- 行业接口未披露可核验日期，所以不据此计算 A股行业周涨跌。美股板块采用有同源收盘端点的 ETF，明确可用样本数量。
- 重要消息只取已留存、发布时间属于该交易周的报道。已确认日程只展示下一周中、生成时仍未发生的官方发布。历史周报会标明实际生成时间，不冒充当时已发布的报告。

`--backfill` 补录该周与前两周的免费日线：A股先用搜狐，再用东财；美股先用 Yahoo 两个入口，股票/ETF与纳指可用 Nasdaq，标普可用 Cboe。日线时点表示正式收盘语义；采集时间保持当前时间，来源和 `origin=backfill` 保留。重复补录同一日线不会新增记录。来源不可用时保留缺项，不用零值替代。

## 事件跟踪

日报会保存已展示的官方日程，并自动关联附近三天的发布前报道、发布后两天的相关快讯。重点消息本身及其观察方向也随日报图片和文字留存，可按关键词回看。数值自动识别采用明确的“美国、统计月份、指标、数值、单位”格式；条件假设、陈旧月份、发布时间不符和仅有事后预测的报道不提升为可比较结果。

事件日程目前覆盖 BLS 的非农/失业率、CPI、PPI、JOLTS、就业成本；明确数值自动解析覆盖前四类，其他格式保留原报道，并支持人工核验后录入。

发布后七天内，日报、周报及 `review events` 会尝试 BLS 无需密钥的公开 API。非农由同一版本的季调就业总人数月差计算，失业率采用官方季调数值；CPI/PPI 同比采用未季调指数、环比采用季调指数计算并按官方常用一位小数记录，CPI 同时保留核心口径。非农、CPI、PPI和失业率分别用稳定 series ID。API 尚未更新、目标统计月份缺失或序列不足时继续待确认，已取得的指标不会因重试新增记录。

官方 API 未披露单次数值的发布时间，因此证据时钟按实际采集时间记录，`source_published_at=null`、`time_basis` 明示该限制；不冒充发布瞬间的初值。完整原始 JSON 序列一并保存在 `series_payload`，后续数据修订仍能核对当时的基准与计算输入。前期值使用同一采集版本，可能包含修订。复盘优先采用官方 API，若有 `--verified` 人工核验记录则采用最新核验记录，新闻证据继续保留。

```bash
python -m review events --archive archive

# EVENT_ID 从上一命令输出取得；数字仅为录入示例，不是实际发布值
python -m review result EVENT_ID --archive archive \
  --metric '非农新增就业' --period 2026-09 --value 15 --unit 万人 \
  --source '美国劳工统计局' \
  --url 'https://www.bls.gov/news.release/empsit.nr0.htm' \
  --published-at '2026-10-02T08:30:00-04:00' --verified
```

`expectation` 使用相同参数。支持非农新增就业（万人）、失业率、CPI/PPI及核心同比/环比（%）、JOLTS职位空缺（万个）、就业成本环比（%）。季度指标的 `--period` 使用该季度最后月份。`--previous` 可附带同一报道中的前值；前值按该报道版本解释，不声称未修订。

必须提供数值来源及 HTTP(S) 地址、统计月份、单位和带时区的发布时间。结果不能早于事件发布；预期必须在发布前公开。发布后补录的事前预测会保留，但不用于声称项目当时已掌握的预期。只有同指标、同月份、同单位且发布前已留存的预期才能比较；不同来源发布数字冲突时标为待核实。核验正文后可用 `--verified` 明确记录，复盘采用最新人工核验结果并注明，原报道和旧证据保留。

市场反应仅使用已经归档、非缓存、同源同单位的报价，列明实际观察窗口。标普使用价格变动，十年美债收益率采用基点变化；观察窗口不足就不显示。它记录发布前后价格变化，不把相关性当作单一事件的因果。

## 历史浏览

```bash
python -m review history --archive archive
python -m http.server 8000 --directory archive
```

浏览器打开 `archive/index.html`，或访问 `http://localhost:8000/`。页面支持日期、市场、时段、关键词及历史版本筛选，默认每个版面显示最新版本。完整数据与图片、文字处于同一版本目录，不会在后续运行中改变。

## 定时运行与备份

`.github/workflows/briefs.yml` 在工作日北京时间08:00、15:30生成 A股精选，美东08:00、16:30生成美股精选；休市日跳过，半日市的美股盘后仍在16:30生成。周报为北京时间周六10:15。GitHub 的定时任务可能延迟，图片保留实际生成和行情时间。手动运行可选择全部、单一市场或周报。

Actions 使用同一个并发组，任务先下载最新 `market-archive`，运行后上传完整 `archive/`，包括本次已提交但尚未成功出图的采集结果。恢复失败会停止生成，避免以空历史覆盖已有归档。每个新 artifact 都包含此前全部历史，90天保留期针对 artifact 本身，不会逐条清理历史数据。

需要仓库启用 Actions 且有可用存储额度。若连续90天没有新归档，GitHub可能过期删除最后一份 artifact；应定期下载整份归档作为长期备份。页面、原数据与数据库都在归档中。

本地运行需要持久磁盘。容器或定时运行器应挂载 `archive/`，使用固定绝对路径。备份时暂停写入任务，再复制整个归档目录；恢复整个目录后继续指定相同 `--archive` 即可。GitHub runner 任务结束后数据库连接已关闭，上传的是完整、可恢复的目录。
