# 历史与复盘

## 保存、重复运行与覆盖

所有模块应共用一个 `--archive` 目录。`--output` 只改变便于发布的 PNG/TXT 位置；归档与短期行情缓存独立。

```text
archive/
  market.sqlite3                    行情快照、当前简报、日程与证据
  index.html                        历史回看入口
  reports/日期/市场-时段/产物目录/
    image.png                       图片
    summary.txt                     精简文字
    data.json                       完整采集快照、版面与采集时点
```

日报按市场、时段、版面日期判断是否已完成；周报按交易周对应的周六日期判断。已有合格完整结果时，默认提示并跳过，不请求行情或更新事件证据，同时从归档恢复公开输出文件。

`--force` 会重新生成并替换该版面的图片、文字和 JSON。即使输入没变也重新绘图，可用于更新排版。不带 `--date` 时会重新采集行情；带 `--date` 时先使用已有简报或原始留存，更新当前行情请省略 `--date`。每个日期、每种简报只展示当前结果，被替换的产物目录会清理；其他日期的简报不受影响。

原始行情、新闻和来源按规范化 JSON 去重保存。带时区时间统一记录为 UTC，行情的原始时点继续保留；相同快照只更新首次/最近采集时间。强制覆盖简报不会删除快照或事件证据，因此周报和复盘仍有历史依据。

日报生成时，参考同市场最近96小时内上一份完整简报实际选中的关键消息。同一原文仅忽略空白、引号等排版差异，降低精选优先级；数字、小数、正负号与百分号保留，出现新数字或新文字的报道继续按新消息处理。只降权，不删除消息，也不改写来源。缺少更重要的新消息时，仍可保留原消息。

强制覆盖排除该日期、该时段自己的原结果；不参考未来生成的简报、另一市场的简报或缺失产物。原始采集快照保留未调整的新闻，简报 JSON 保存用于图片与文字的实际评分。

### 指定日报日期

```bash
python -m ashare close --date 2026-09-30
python -m ashare close --date 2026-09-30 --force
python -m usstock premarket --date 2026-10-01
python -m usstock postmarket --date 2026-09-30 --force
```

`--date YYYY-MM-DD` 指定版面交易日，A股使用北京时间日期，美股使用纽约日期。日期必须在各自日历覆盖范围内且为交易日；休市日报错，不会改成前后交易日。无此参数时继续按实际运行时点选择早盘/盘前或已完成收盘日期。

任意未来日期不支持；早盘或盘前只允许指定默认即将交易的日期，并且需要单独选择该时段。

历史运行先检查该市场、时段、日期的已有完整简报，默认复用并恢复公开输出。`--force` 使用该版已保存的数据重绘，可将旧纵版更新为1620×1080横版；简报无法使用时，再查可用于该日期的原始采集。历史版面不会采集今天的行情或新闻，也不补造当时的预期、日程和盘前价格。

如果原简报在版面日期结束后才生成，指定日期运行会先清理晚于该日的消息和无法确认日期的字段，再替换结果，避免直接复用混有次日资讯的简报。历史补录与稍后快照恢复会标明“历史参考”，文字版记录实际采集时间；原始采集快照继续保留。

没有可用留存时，仅能重建日线能够支持的有限内容：

| 版面 | 历史日线补录的范围与限制 |
| --- | --- |
| A股收盘 | 对应交易日指数及沪市成交额等可取得日线；行业、资金、涨跌家数和新闻缺失时注明 |
| A股早盘 | 对应开盘前已结束的海外常规场指数；历史消息与当天盘前快照无法由日线恢复 |
| 美股盘后 | 对应交易日的常规场指数、个股或ETF日线；延长交易与当时新闻不补造 |
| 美股盘前 | 常规前收不能替代盘前、夜盘报价；缺少可用归档直接报错 |

补录来源与真实采集时点保留，数据缺项不以零值替代。新补录仅反映供应商目前提供的历史数据，可能含修订；与当时已保存的快照区分。已有简报重绘继续保留原行情时点。A股早盘日线版同时使用上个A股交易日的指数与成交额。指定日期的 `all` 仍分别处理时段，保留合格结果，最后报告未完成项。

### 日报成稿门槛

只检查组装后通过该时段筛选的核心报价，至少有一条有效正价格；涨跌幅、板块、资金、成交额等次要字段缺失可注明后继续生成。

| 版面 | 核心报价 |
| --- | --- |
| A股早盘 | 道指、纳指、标普500或日经225 |
| A股收盘 | 同参考日的上证、深成指、创业板或科创50 |
| 美股盘前 | 本版股指期货，或已通过时点筛选的夜盘、盘前、近期盘后参考个股 |
| 美股盘后 | 本版已完成常规场的主指数；陈旧收盘或延长交易不补位 |

核心报价不足时不绘图、不登记本次成功结果，保留采集快照并提示原因；命令返回非零状态，正常重复运行即可重试。强制运行遇到数据不足也保留原合格结果。文件齐全但核心行情不足的记录视为未完成。

`all` 分别尝试待生成的时段，合格的简报正常发布；有时段不足则在处理完其余时段后报告失败，后续重试复用已经成功的简报，只采集、补齐尚未完成的时段。

### 并发与失败恢复

- 同一归档的命令用系统文件锁串行运行；等待结束后重新检查结果，进程退出自动释放锁。
- 原始数据在组装和绘图之前提交。采集已完成而生成失败时，原始快照仍然留存；直接重试即可。
- 图片、文字、JSON 先完整生成，再用 SQLite 写事务切换索引；并发发布在事务内再次检查已有结果。
- 强制生成失败不删除原成功归档。公开 PNG/TXT 分别原子替换；若输出中断导致文件不齐，重复运行会从当前成功归档恢复一致内容。
- 归档产物缺失或日报核心行情不足时不当作成功结果；历史日期先尝试原始留存或允许的日线补录，当前日期按正常采集流程重试。中断留下的临时目录在下次成功发布该版面时清理。

`archive/` 和 `output/` 不提交到 main。`.cache/briefs/` 可独立删除，持久归档不要随缓存清理。

## 每周精选

```bash
python -m weekly
python -m weekly --week 2026-09-21 --backfill
python -m weekly --week 2026-09-21 --backfill --force
```

默认选择美东周五20:00已结束的最近交易周。显式 `--week` 必须是周一，尚未结束的周会拒绝生成；文件按该周周六命名，图片同时标明交易周和实际生成时间。

周涨跌比较上周与本周最后实际交易日的同源、同单位收盘，不累加日涨跌幅，缺少端点不使用较早日代替。中间缺日不妨碍已知端点的涨跌计算，但会说明留存天数；日均量能要求每个应交易日都有同源数据，交易日数量不同时各自取日均值。

A股量能采用沪市人民币成交额，美股采用 SPY 供应商日线成交股数代理，两者不可直接比较。A股行业没有可核验的行情日期，不计算行业周涨跌；美股板块使用有同源端点的 ETF。

重要消息只取交易周内已留存的日报精选。日程只展示下一周中、生成时仍未发生的官方发布。历史周报标明实际生成时间，不冒充当时已发布的简报。

`--backfill` 补录指定周与前两周的免费日线。A股用搜狐→东方财富；美股用 Yahoo 两个入口→Nasdaq 或 Cboe。来源和实际采集时间保留，`origin=backfill` 标明补录，时点仅代表正式收盘语义。同源同一天的数据重复补录不会新增快照；缺项不以零值替代，也不补造旧新闻或事前预期。已有周报仍默认跳过，补录并更新周报需同时用 `--force`。

## 事件跟踪与录入

日报保存展示过的官方日程，关联发布前三天和发布后两天的相关报道。数值解析要求明确的美国指标、统计月份、数值和单位；假设、陈旧月份、不符发布时间的报道只留存原文。

日程覆盖 BLS 的非农/失业率、CPI、PPI、JOLTS、就业成本，以及美联储官方 FOMC 利率决议与新闻发布会。FOMC 两项分别保存官方时间并关联相关报道；利率决定、声明内容不从报道自动推断成数值结果。

发布后七天内，日报、周报和 `review events` 尝试免费 BLS API 补取非农、失业率、CPI及PPI；目标月份尚未更新则继续待确认，已取得的官方指标不重复请求。

非农按同批采集的季调总就业人数月差计算，千人转万人。CPI/PPI同比用未季调指数，环比用季调指数，按一位小数记录；CPI同时保留核心口径。完整原始序列存为 `series_payload`，保留 series ID、来源和计算方法。

API没有披露单次数值的真实发布时间，证据按采集时点记录，`source_published_at=null` 与 `time_basis` 明示限制；数据可能包含后续修订，不冒充发布瞬间的初值。前期值来自同批采集的数据。

```bash
python -m review events

# EVENT_ID 从上一命令取得；数值仅为录入示例
python -m review result EVENT_ID \
  --metric '非农新增就业' --period 2026-09 --value 15 --unit 万人 \
  --source '美国劳工统计局' \
  --url 'https://www.bls.gov/news.release/empsit.nr0.htm' \
  --published-at '2026-10-02T08:30:00-04:00' --verified
```

`expectation` 使用相同参数。必填事件编号、指标、统计月份、数值、单位、来源、HTTP(S)网址和带时区的发布时间。`--previous` 可附同一报道的前值；`--verified` 表示人工核验过来源正文。支持非农新增就业（万人）、失业率、CPI/PPI及核心同比/环比（%）、JOLTS职位空缺（万个）、就业成本环比（%）；季度指标的月份取季度最后月。

结果不能早于事件发布；预期必须在发布前公开。只有发布前已留存、指标/月份/单位一致的预期才参与比较，事后补录的预测不会当作当时已经掌握的信息。来源冲突时标为待核实；复盘优先采用最新人工核验记录，其次官方 API，原证据保留。

行情反应只用已归档、非缓存、同源同单位的报价，附实际观察窗口。标普使用价格变化，十年美债收益率使用基点；窗口不足就不展示，不把相关性当作事件因果。

## 历史浏览、定时运行与备份

```bash
python -m review history --archive archive
python -m http.server 8000 --directory archive
```

直接打开 `archive/index.html` 或访问 `http://localhost:8000/`。页面按日期、市场、时段和关键词筛选，每份简报链接到对应的图片、文字和完整数据，同时显示事件证据。

`.github/workflows/briefs.yml` 是唯一工作流，用于运行和保存数据，没有测试或覆盖率 CI。工作日北京时间08:00、15:30生成 A股精选，美东08:00、16:30生成美股精选，休市日跳过；半日市盘后仍在16:30生成。北京时间周六10:15生成周报。GitHub定时任务可能延迟，图片保留实际时点。

手动运行的 `edition` 可选全部日报、单一市场、单一时段或周报：`all`、`ashare`、`ashare-morning`、`ashare-close`、`usstock`、`usstock-premarket`、`usstock-postmarket`、`weekly`。`date` 为可选的 `YYYY-MM-DD`，日报按本市场交易日使用，周报转换为该日期所在周的周一再传 `--week`；未结束交易周仍拒绝生成。`force` 默认为关闭。选择全部日报时，某市场失败后继续尝试另一市场，历史页面仍更新，最终以非零状态报告失败。

运行页底部 Artifacts 中的 `market-briefs` 只包含该次生成或复用的 PNG/TXT，压缩包内直接是文件，无需在归档目录中寻找。图片统一为1620×1080横版；复用旧纵版会保持原文件，需指定日期并勾选 `force` 重绘。此包保留30天，需登录 GitHub 下载；有部分失败时仍上传已完成输出，没有文件时不创建此包。

Actions 共用一个并发组，先下载最新 `market-archive`，结束后上传完整归档，中途失败也保存已提交的采集数据。恢复失败会停止生成并禁止上传空归档。每份 artifact 包含此前完整历史，90天保留期针对 artifact 本身，不会逐条删除数据库记录；连续90天未生成新归档时，最后一份也可能过期，应定期下载长期备份。

本地任务使用固定工作目录或绝对归档路径，容器应挂载持久 `archive/`。备份前暂停写入任务，复制整个归档目录；恢复时也恢复整个目录，并继续指定相同 `--archive`。
