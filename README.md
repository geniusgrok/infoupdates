# A股早盘 / 收盘信息图

用公开行情生成 **1080×1620** 的深色精选信息图：白灰文字、红涨绿跌、琥珀色强调，按卡片分组并突出关键数字。标题包含日期和星期。

- **收盘精选**：主要股指、涨跌家数、涨停跌停、板块表现、收盘看点、主力与跨境资金、外围参考，以及一句话市场情绪和量能。未完成收盘的行情标为盘中快照，量能待确认。
- **早盘精选**：外盘概览、美日韩涨跌、隔夜要闻、今日关注。交易日 15:00 前生成时使用当天版面日期；收盘后、周末和假日生成时使用下一个真实交易日。A 股参考行情保留其实际交易日期，不把长假前的行情称作“昨日”。

## 运行

```bash
pip install -r requirements.txt
python -m a_share_brief all
```

只出一张：

```bash
python -m a_share_brief close
python -m a_share_brief morning
```

图片写到 `output/close-YYYY-MM-DD.png` 和 `output/morning-YYYY-MM-DD.png`；文件名日期与图片标题一致。同名的 `.txt` 是配图文案，可以和图片一起发。可用 `--output 路径` 指定输出目录。

例如 2026 年 9 月 30 日收盘后生成时，收盘文件为 `close-2026-09-30.png`，早盘文件为 `morning-2026-10-08.png`，跨过国庆休市。

交易日历按上交所休市公告维护，目前覆盖 **2025、2026 年**，休市范围和公告链接在 `a_share_brief/models.py`。新年度使用前应按交易所公告补充 `HOLIDAY_RANGES` 并运行测试；调休周末仍不开市。未覆盖的早盘版面年份会明确报错，包括跨年时所需的下一年；收盘版仍可生成，量能比较待确认。

## 数据

| 内容 | 主源 | 备用 |
| --- | --- | --- |
| A股指数 | 新浪财经 | 腾讯行情 |
| 外盘、汇率 | 新浪财经 | 腾讯行情补道指、纳指、标普、恒生和在岸人民币 |
| 日经、韩国指数 | 新浪财经 | — |
| 行业涨跌 | 新浪行业 | 新浪资金接口里的涨跌幅 |
| 涨跌分布、涨停跌停、沪深港通 | 东方财富 | — |
| 主力资金 | 东方财富 | 腾讯资金流 |
| 行业资金 | 东方财富 | 新浪行业资金 |
| 快讯 | 华尔街见闻 | 东方财富快讯 |
| 沪市成交额较上日变化 | 搜狐历史行情 | — |

单个接口失败时保留可用数据，缺失数字显示 `—`，相应结论标为待确认。主源失败时尝试表中备用接口；备用源只覆盖其支持的字段，不能保证补齐整组数据。图底会注明数据缺失或替代来源。沪市和深市、北向和南向分别请求，只有完整且日期一致的沪深数据才显示合计。

市场情绪根据个股涨跌分布概括为低落、平淡或高涨。量能使用同源搜狐历史行情的**沪市全日成交额**，与上一个真实交易日比较：变化在 ±5% 内为基本平量，超过范围为放量或缩量。图上写实际增加或减少的人民币金额，例如“沪市成交额较上日增加 176.9 亿元”，不显示百分比，也不使用“亿股”。盘中、日期不一致或历史数据缺失时，量能待确认。沪深总成交额与沪市量能比较分别标注。

北向资金的每日净买入不再披露，图上只保留北向成交额，并写明这一点。南向净买入仍按公开数据展示，单位是港元。

行业涨跌主要用新浪行业，行业资金主要用东方财富行业，两套分类不一样，图上分别标注实际来源。这些行业接口缺少可核验的交易日期元数据，暂不能保证其数据与指数属于同一交易日。

快讯会丢掉减持、辞职、拍卖这类公司公告，并控制同一主题的条数。收评、宏观数据和市场资金优先。
