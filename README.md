# A股早盘 / 收盘信息图

用公开行情生成两张深色长图，风格接近彭博终端和华尔街见闻信息图：红涨绿跌，大数字，分区清楚。

- **收盘综述**：主要股指、涨跌家数、涨停跌停、板块涨跌、主力资金、南向资金、外围市场，以及一句话市场方向。日期和周几写在标题旁边。
- **早盘**：每个交易日早上用。看昨日情绪、昨日指数和板块、隔夜美日韩、隔夜消息、今日关注板块。上午生成时标题日期是当天；收盘后生成时，标题日期落到下一个工作日。

## 运行

```bash
pip install -r requirements.txt
python -m a_share_brief all
```

只出一张：

```bash
python -m a_share_brief close
python -m a_share_brief morning
```

图片写到 `output/close-YYYY-MM-DD.png` 和 `output/morning-YYYY-MM-DD.png`。同名的 `.txt` 是配图文案，可以和图片一起发。

## 数据

| 内容 | 主源 | 备用 |
| --- | --- | --- |
| A股指数 | 新浪财经 | 腾讯行情 |
| 外盘、汇率 | 新浪财经 | 腾讯行情 |
| 期货、日经 | 新浪财经 | — |
| 行业涨跌 | 新浪行业 | 新浪资金接口里的涨跌幅 |
| 上证走势 | 新浪K线 | 腾讯K线 |
| 涨跌分布、涨停跌停、沪深港通 | 东方财富 | 沪市和深市、北向和南向分开请求 |
| 主力资金 | 东方财富 | 腾讯资金流 |
| 行业资金 | 东方财富 | 新浪行业资金 |
| 快讯 | 华尔街见闻 | 东方财富快讯 |

单个接口失败不会中断出图。主源失败时改用备用源，图底会注明；两边都失败时，只空出那一块。

北向资金的每日净买入不再披露，图上只保留北向成交额，并写明这一点。南向净买入仍按公开数据展示，单位是港元。

行业涨跌用的是新浪行业，行业资金用的是东方财富行业，两套分类不一样，图上分别标注。

快讯会丢掉减持、辞职、拍卖这类公司公告，并控制同一主题的条数。收评、宏观数据和市场资金优先。
