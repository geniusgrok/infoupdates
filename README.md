# A股 / 美股市场精选信息图

用公开行情生成 **1080×1620** 的深色精选信息图：白灰文字、红涨绿跌、琥珀色强调，按卡片分组并突出关键数字。标题包含日期和星期。

- **A股收盘精选**：主要股指、涨跌家数、涨停跌停、板块表现、收盘看点、主力与跨境资金、外围参考，以及一句话市场情绪和量能。未完成收盘的行情标为盘中快照，量能待确认。
- **A股早盘精选**：外盘概览、美日韩涨跌、隔夜要闻、今日关注。交易日 15:00 前生成时使用当天版面日期；收盘后、周末和假日生成时使用下一个真实交易日。A 股参考行情保留其实际交易日期，不把长假前的行情称作“昨日”。
- **美股盘前精选**：股指期货、上一交易日指数、七巨头盘前报价、行业 ETF、宏观参考和精选快讯。盘前报价缺失时明确标注，并保留其实际参考日期。
- **美股盘后精选**：四大指数、行业 ETF、七巨头、市场情绪、SPY 成交股数及宏观参考。指数保留正式收盘数据；七巨头的收盘与盘后延长交易价格、涨跌和时点分别标明，缺失最新收盘时注明实际参考日期。

`ashare/` 封装 A 股业务，`usstock/` 封装美股业务；`brief_common/` 仅共享 HTTP、数字格式、新闻基础结构和排版工具。两个市场各自维护交易日历、行情含义和内容组织。

## 运行

```bash
pip install -r requirements.txt
python -m ashare all
python -m usstock all
```

只出一张：

```bash
python -m ashare close
python -m ashare morning
python -m usstock premarket
python -m usstock postmarket
```

| 命令 | 输出文件名前缀 | 内容 |
| --- | --- | --- |
| `python -m ashare all` | `close-`、`morning-` | A 股两张图 |
| `python -m usstock all` | `us-premarket-`、`us-postmarket-` | 美股两张图 |

图片写到 `output/前缀YYYY-MM-DD.png`；文件名日期与图片标题一致。同名的 `.txt` 是完整配图文案，包含图片精选之外的新闻、数据时间及缺失说明。可用 `--output 路径` 指定输出目录。原有 `python -m a_share_brief` 命令和 Python 导入继续兼容，实际 A 股实现位于 `ashare/`。

例如 2026 年 9 月 30 日收盘后生成时，收盘文件为 `close-2026-09-30.png`，早盘文件为 `morning-2026-10-08.png`，跨过国庆休市。

交易日历按上交所休市公告维护，目前覆盖 **2025、2026 年**，休市范围和公告链接在 `ashare/models.py`。新年度使用前应按交易所公告补充 `HOLIDAY_RANGES` 并运行测试；调休周末仍不开市。未覆盖的早盘版面年份会明确报错，包括跨年时所需的下一年；A 股收盘版仍可生成，量能比较待确认。

美股日期按 `America/New_York` 美东时区计算，自动切换冬令时与夏令时。`usstock/calendar.py` 按 [NYSE 官方日历](https://www.nyse.com/markets/hours-calendars)维护 **2024–2028 年**休市及提前收盘日：常规交易为 09:30–16:00，半日市在 13:00 收盘；盘后延长交易通常到 20:00，半日市到 17:00。盘前版指向即将开盘的交易日，盘后版指向最近完成收盘的交易日；周末、节假日及跨年也按日历处理。请求日期或必要的相邻交易日超出覆盖范围时，美股 CLI 会明确报错，应先按官方公告更新日历再运行；临时停市也需要维护。

例如美东 2026 年 10 月 1 日 17:00 生成时，美股盘后为 `us-postmarket-2026-10-01.png`，盘前为 `us-premarket-2026-10-02.png`。`all` 使用一次行情抓取和同一个生成时间，两个市场的命令可以写入同一输出目录。

## A股数据

| 内容 | 主源 | 备用 |
| --- | --- | --- |
| A股指数 | 新浪财经 | 腾讯行情 |
| 外盘、汇率 | 新浪财经 | 腾讯行情补道指、纳指、标普、恒生和在岸人民币 |
| 日经、韩国指数 | 新浪财经 | — |
| 行业涨跌 | 新浪行业 | 新浪资金接口里的涨跌幅 |
| 涨跌分布、涨停跌停、沪深港通 | 东方财富 | — |
| 主力资金 | 东方财富 | 腾讯资金流 |
| 行业资金 | 东方财富 | 新浪行业资金 |
| 快讯 | 华尔街见闻 | 东方财富快讯 |
| 沪市成交额较上日变化 | 搜狐历史行情 | — |

单个接口失败时保留可用数据，缺失数字显示 `—`，相应结论标为待确认。主源失败时尝试表中备用接口；备用源只覆盖其支持的字段，不能保证补齐整组数据。图底会注明数据缺失或替代来源。沪市和深市、北向和南向分别请求，只有完整且日期一致的沪深数据才显示合计。

市场情绪根据个股涨跌分布概括为低落、平淡或高涨。量能使用同源搜狐历史行情的**沪市全日成交额**，与上一个真实交易日比较：变化在 ±5% 内为基本平量，超过范围为放量或缩量。图上写实际增加或减少的人民币金额，例如“沪市成交额较上日增加 176.9 亿元”，不显示百分比，也不使用“亿股”。盘中、日期不一致或历史数据缺失时，量能待确认。沪深总成交额与沪市量能比较分别标注。

北向资金的每日净买入不再披露，图上只保留北向成交额，并写明这一点。南向净买入仍按公开数据展示，单位是港元。

行业涨跌主要用新浪行业，行业资金主要用东方财富行业，两套分类不一样，图上分别标注实际来源。这些行业接口缺少可核验的交易日期元数据，暂不能保证其数据与指数属于同一交易日。

快讯会丢掉减持、辞职、拍卖这类公司公告，并控制同一主题的条数。收评、宏观数据和市场资金优先。

## 美股数据

| 内容 | 数据源 / 口径 |
| --- | --- |
| 指数、期货、七巨头、行业 ETF | Yahoo Finance v8 chart，`query1` 主域、`query2` 备用域，无需 API key |
| 波动率、美债收益率、美元、黄金、原油 | Yahoo Finance 对应指数或期货 |
| 盘前、盘后报价 | 接口实际返回的延长交易时段数据，保留报价时间与交易时段 |
| 量能 | SPY 正常交易时段成交股数，与上一交易日同源数据比较 |
| 中文快讯 | 华尔街见闻，东方财富备用；筛选美股、美国宏观、能源和相关全球事件 |

指数取正式交易时段行情；七巨头的盘前报价逐项标明，缺失时可展示明确标为“前收”的行情，不把正式收盘价当成盘前实时价格。盘后版的七巨头主行保留正式收盘涨跌，副行显示可用的盘后延长交易价格、涨跌和时点；完整文案将两类行情分别列出，延长交易不替代正式收盘价。期货和大宗商品的交易时间与股票不同，显示其实际时间，缺失或过期时不作实时结论。行业 ETF 是行业表现的参考，不能代表全市场个股涨跌家数。

美股情绪由可核验的指数表现与行业 ETF 涨跌概括，盘前当日有足够期货报价时使用期货方向作参考；VIX 单独作为宏观参考展示。量能仅使用 **SPY 成交股数代理**，不是美股总成交额，也不是资金净流入。显示具体股数和较上日变化，不虚构美元主力资金。日期不一致、正式交易尚未完成或上一日数据缺失时，量能待确认。

Yahoo 等公开接口可能延迟、限流或缺少延长交易数据；同域备用不保证补齐字段。数据缺失显示 `—`，对应判断标为待确认，完整说明保留在 `.txt`。中文快讯属于精选事件信息，不能替代完整的美股公告和财经日历。
