# A 股 / 美股市场精选

把公开行情和中文快讯整理成 **1080×1620** 信息图与配图文案。采用深色背景、白灰文字、红涨绿跌、琥珀色强调；标题包含日期和星期，摘要包含市场情绪和量能。

## 运行

需要 Python 3.10+：

```bash
pip install -r requirements.txt
python -m ashare all
python -m usstock all
```

| 命令 | 内容 | 文件前缀 |
| --- | --- | --- |
| `python -m ashare close` | A 股收盘精选 | `close-` |
| `python -m ashare morning` | A 股早盘精选 | `morning-` |
| `python -m usstock premarket` | 美股盘前精选 | `us-premarket-` |
| `python -m usstock postmarket` | 美股盘后精选 | `us-postmarket-` |

`all` 一次抓取生成该市场两张图。默认输出到 `output/`，可用 `--output 路径` 修改。文件名日期与图片标题一致；同名 `.txt` 包含配图文案和数据说明。美股文案逐项列出时点与来源，A 股早盘文案包含精选要闻。

## 目录

```text
ashare/             A 股行情、交易日历、内容和输出
usstock/            美股行情、交易日历、内容和输出
  sources/          Yahoo、Nasdaq、Cboe、Futu、Webull 接口
common/             HTTP、缓存、数字格式、快讯和画布
assets/fonts/       中文字体与许可证
tests/              按市场和数据源命名的回归测试
docs/sources.md     免费来源、覆盖范围与数据口径
```

两个市场独立维护数据含义。`sources` 负责请求和解析，`data` 负责备用源切换，`compose` 按交易日和时段组装内容，`render` 与 `social` 输出图片和文案。旧包名与旧兼容层已移除。

## 行情规则

- A 股指数按缺项和行情日期切换备用；美股按日期、时段和比较基准校验，其他字段按接口覆盖尝试独立来源。保留整条同源报价，不把不同来源的价格、前收和成交量拼在一起。
- 美股盘前展示真实盘前、夜盘，或明确标注的最近盘后参考。常规前收只作涨跌基准。Yahoo 夜盘保留真实成交时间；Webull 夜盘备用标为快照，注明采集时间与“成交时间未披露”。
- 美股盘后区分常规收盘与盘后延长交易。指数采用完成的常规场；个股分别列出收盘和盘后价格。期货和商品保留供应商的参考基准与延迟说明。
- A 股量能采用同源的**沪市全日成交额**，显示较上日增加或减少多少亿元。美股采用 **SPY 成交股数代理**，不能代表全市场成交额。盘中、缺少上一交易日或日期不一致时，量能待确认。
- 缺失数字显示 `—`，依据不足的判断标为待确认。公开接口可能延迟、限流或变更；实际覆盖和验证结果见[数据来源](docs/sources.md)。

美股缓存只在独立在线来源无法补齐时使用，保留原行情时间并标明“缓存”。夜盘快照保留原采集时间，不因读取缓存更新时点。缓存位于 `.cache/briefs/`，可用环境变量 `BRIEF_CACHE_DIR` 指定目录。删除缓存目录即可清除。

## 交易日期

A 股使用北京时间，日历覆盖 **2025–2026** 年。早盘版指向即将交易的日期，收盘版保留实际行情日期。国庆休市期间，2026-09-30 收盘版对应的下一张早盘版为 2026-10-08。

美股使用 `America/New_York`，自动处理夏令时。NYSE 日历覆盖 **2024–2028** 年；常规场 09:30–16:00，半日市 13:00 收盘；盘后通常至 20:00，半日市至 17:00。盘前版指向即将开盘的交易日，盘后版指向最近完成收盘的交易日。夜盘按该交易日前一自然日 20:00 至当日 04:00 校验，周日夜盘属于周一版面。

日历范围和交易所公告位于 `ashare/calendar.py` 与 `usstock/calendar.py`。新增年度或遇临时停市时应先更新日历。A 股早盘及美股版面超出覆盖范围会明确报错；A 股收盘可保留实际行情日期，并注明量能比较待确认。

## 验证

```bash
python -m unittest discover -s tests -v
```

测试覆盖来源解析、独立备用切换、同源比较基准、缓存、假日与半日市、跨午夜夜盘、时间校验，以及文本和图片排版。

行情仅供参考，不构成投资建议。中文字体为 [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)，许可证见 `assets/fonts/OFL.txt`。
